เพิ่ม/แก้ไขระบบ

ตั้งค่า API อัพโหลดรูปโปรไฟล์นักเรียน (Google Apps Script)

ระบบจะใช้ GAS Web App รับไฟล์รูปและบันทึกลง Google Drive แล้วส่ง URL กลับมาเก็บใน core_students.avatar_students_url

วิธีเตรียม GAS

  1. สร้าง Google Apps Script ใหม่ → วางโค้ดรับไฟล์และบันทึกลง Drive
  2. Deploy → New Deployment → Web App → Execute as: Me, Access: Anyone
  3. คัดลอก Deployment URL (/exec) มาวางด้านล่าง
  4. คัดลอก ID โฟลเดอร์ Drive ที่ต้องการเก็บรูปมาวาง
💡 ID โฟลเดอร์อยู่ใน URL ของ Google Drive
drive.google.com/drive/folders/[ID ตรงนี้]
