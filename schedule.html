ดู/แก้ไขตารางสอนของครูทุกคน

รายวิชาของฉัน

ลากวิชาไปวางในตาราง หรือคลิกเลือก

กำลังโหลดรายวิชา...

คำแนะนำ: ลากวิชาจากกล่องด้านซ้ายมาวางในช่องตาราง (บันทึกอัตโนมัติ) · คลิกที่วิชาในช่องเพื่อลบออก

เพิ่มรายวิชาใหม่

เลือกสีเพื่อให้ง่ายต่อการมองเห็นในตาราง
Tip: หากสอนหลายห้อง สามารถใช้ปุ่ม คัดลอก ที่การ์ดวิชาเพื่อสร้างวิชาเดียวกันหลายห้องได้ทันที

ตั้งค่าการแจ้งเตือน Telegram

วิธีขอ Token & Chat ID

  1. คุยกับ @BotFather ใน Telegram → สร้าง Bot ใหม่ → รับ Bot Token
  2. ส่งข้อความหา Bot ของท่าน 1 ครั้ง
  3. เปิดลิงก์ api.telegram.org/bot[TOKEN]/getUpdates → เอา Chat ID

เปิดใช้งานแจ้งเตือน

แจ้งเตือนผ่าน Telegram ตามเวลาที่กำหนด

แจ้งเตือนสรุปตารางสอนรายวัน

ส่งสรุปตารางสอนทั้งหมดของวันนั้นๆ

แจ้งเตือนก่อนคาบ 5 นาที

ส่งเตือนคาบถัดไปพร้อมรายละเอียด

หมายเหตุ: การแจ้งเตือนจะทำงานเมื่อ เปิดหน้านี้ค้างไว้ เท่านั้น (ทำงานฝั่ง Client) — สำหรับ Production แนะนำใช้ Supabase Edge Function + pg_cron
